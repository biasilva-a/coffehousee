#  CoffeeHouse — Simulado SAEP

Projeto desenvolvido como parte de um **simulado do SAEP**, com foco na criação de uma aplicação web para uma cafeteria.

## Tecnologias utilizadas

* **Node.js**
* **Express**
* **HTML5**
* **CSS3**
* **JavaScript**
* **PostgreSQL** — configuração e gerenciamento do banco de dados
